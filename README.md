# ASB

Open `index.html` directly in your browser. No installation, API key, account or build command is required.

## Update the GitHub Pages website

1. Open the repository's **Code** tab.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css` and `script.js` from this folder directly into the repository root, replacing the old versions. Do not upload the enclosing folder or ZIP as the website.
4. Commit the changes to the branch configured in **Settings → Pages** (usually `main`, folder `/ (root)`).
5. Wait for the Pages deployment to finish, then refresh the website. If the old version remains, use a hard refresh (Mac: Command–Shift–R).

Do not remove or rename `index.html`. This release has no extra dependencies or PDFs to upload.

## Included content

Exactly seven classes: Accounting, Algebra, Microeconomics, Financial Maths, Digital Business Management, Contract Law and Business Management Function.

Microeconomics contains 7 lecture topics, 53 flashcards, 61 word-bank entries and 41 practice questions with hints and worked solutions. The six other classes have clearly labelled empty course spaces awaiting lecture material.

The shared revision material is stored inside `script.js`. Every visitor receives the same course material. Nothing is generated by an AI service when someone visits the site. Questions include lecture examples and original revision exercises; they are not official exam questions or a guarantee of examination coverage.

## Formula clarifications

For horizontal good x and vertical good y, the positive rate at which y is given up for x is MRS_xy = MU_x/MU_y. The signed indifference-curve slope is −MU_x/MU_y. Preferences slide 16 prints the reversed ratio, while slide 24 uses the consistent convention. This site explicitly follows slide 24 and explains the discrepancy.

For u(t,c)=t^0.3 c^0.7, differentiation with respect to t leaves c^0.7 unchanged. Thus MU_t=0.3 t^−0.7 c^0.7. Preferences slide 26(c) prints c^−0.7 in that derivative. The site uses the corrected derivative and explains it.

For the concert/babysitting comparison, monetary and non-monetary costs are treated consistently: the next-best net payoff is the opportunity cost used in comparing net benefits. The babysitting payment alone should not be used while ignoring its effort cost.

## Personal data and progress

Personal notes, known-card markers, reviewed topics, question completion and planner tasks use browser localStorage. They are not sent to GitHub or other visitors and do not sync across devices. Clearing browser data or using private browsing may remove them. Moving between a local file and the GitHub website creates separate browser storage contexts.

Existing `studyspace_classes` data is left untouched. Old Microeconomics notes whose topic names match the new topic titles or identifiers are copied into the new personal-note system where possible. Old planner tasks remain in `studyspace_tasks`. New shared course content is independent of any old personal classes.

Question answer drafts are temporary. The completion marker is saved, but typed practice answers are not stored. Written answers are self-marked, not automatically graded. Numeric answers accept decimals and simple fractions with 0.1% tolerance (minimum absolute tolerance 0.0001). Use plain numbers without units or thousands separators.
